# PlatePlotter

**PlatePlotter** е уеб приложение, разработено с Python и Django, предназначено за управление на хранителни продукти, складови наличности, рецепти и седмични хранителни менюта.

Проектът е създаден като част от обучението по **Django Basics в SoftUni** и демонстрира практическо приложение на Django MVT архитектурата, релационни модели, Class-Based Views, форми, валидация и работа с бази данни.

## Основни функционалности

### Магазини и продукти
- Добавяне, преглед, редактиране и изтриване на магазини и продукти.
- Категоризиране на продуктите.
- Поддържане на цени, опаковки, марки и хранителни стойности.
- Търсене на продукти по име и марка.
- Филтриране по категория и магазин.
- Сортиране по име и цена.
- Странициране на резултатите (pagination).
- Валидация на въведените данни.
- Защита срещу изтриване на обекти със защитени релации.

### Складови наличности
- Регистриране на наличните количества.
- Определяне на минимални складови запаси.
- Идентифициране на продукти с количества под определения минимум.

### Ястия и рецепти
- Създаване и управление на ястия.
- Добавяне на продукти към рецепти с конкретни количества.
- Определяне на брой порции.
- Автоматично изчисляване на калории, протеини, въглехидрати и мазнини за една порция.

### Седмично хранително меню
- Създаване на седмични менюта.
- Организиране на храненията по дни и тип хранене.
- Добавяне на готови ястия и отделни продукти.
- Изчисляване на хранителните стойности за всяко хранене.

### Потребителски интерфейс
- Responsive дизайн с Bootstrap 5.
- Навигация между основните модули.
- Форми с пояснения, примерни стойности и съобщения за грешки.
- Съобщения за успешно или неуспешно изпълнени операции.
- Странициране на дълги списъци.
- Персонализирана страница за грешка 404.

## Инсталация и стартиране

### 1. Клониране на хранилището

```bash
git clone https://github.com/AlexanderHrHristov/plate-plotter-django.git
cd plate-plotter-django
```

### 2. Създаване на виртуална среда

```powershell
python -m venv .venv
```

Активиране под Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Инсталиране на зависимостите

```powershell
python -m pip install -r requirements.txt
```

### 4. Създаване на базата данни

```powershell
python manage.py migrate
```

Командата прилага миграциите и създава необходимите таблици в SQLite базата данни.

### 5. Стартиране на приложението

```powershell
python manage.py runserver
```

Приложението ще бъде достъпно на:

http://127.0.0.1:8000/

Не се изисква регистрация на потребител. Данните могат да бъдат създавани и управлявани директно през потребителския интерфейс.

## Архитектура

Приложението използва **Model–View–Template (MVT)** архитектурата на Django.

Проектът е разделен на три основни приложения:

**inventory** — управление на магазини, продукти и наличности.

**meals** — управление на ястия, рецепти и използваните в тях продукти.

**weekmenu** — управление на седмични менюта, хранения и допълнителни продукти.

Използвани са релации `ForeignKey`, `OneToOneField` и `ManyToManyField` с междинни модели.

## Технически особености

- Class-Based Views за основните CRUD операции.
- Django ModelForms за въвеждане и редактиране на данни.
- Персонализирана валидация чрез `clean()` и `ValidationError`.
- Обработка на `ProtectedError` при изтриване на свързани обекти.
- Django messages framework за потребителски съобщения.
- Django ORM за филтриране, търсене и сортиране.
- Pagination за списъци с множество записи.
- Custom template filter `euro` за форматиране на цени.
- Reusable template partials за общи компоненти.
- Персонализирана HTTP 404 страница.
- Използване на Django migrations за управление на структурата на базата данни.

## Хранителни изчисления

Приложението изчислява хранителните стойности на ястията въз основа на количествата на използваните продукти.

За всяко ястие се изчисляват стойностите за една порция според зададения брой порции.

Храненията могат да комбинират готови ястия и допълнителни продукти.

За коректни изчисления е необходимо продуктите да имат попълнени хранителни стойности.

## Ограничения

- Проектът е разработен с учебна и демонстрационна цел.
- Не е реализирана система за потребителска регистрация и удостоверяване.
- Автоматичните изчисления на макронутриенти работят с продукти, чиито количества са зададени в грамове.
- Липсващите хранителни стойности ограничават възможността за автоматично изчисление.
- Използва се локална SQLite база данни.
- Приложението не е предназначено за публична production среда в текущия си вид.
