# PlatePlotter

PlatePlotter е уеб приложение, разработено с Django, предназначено за управление на хранителни продукти, складови наличности, рецепти и седмични хранителни менюта.

Проектът е създаден като част от обучението по **Django Basics в SoftUni**.

## Основни функционалности

- **Управление на магазини** — добавяне, преглед, редактиране и изтриване на магазини.
- **Управление на продукти** — поддържане на хранителни продукти, категории, цени и хранителни стойности.
- **Складови наличности** — проследяване на наличните количества и минималните складови запаси.
- **Рецепти и ястия** — създаване на ястия, добавяне на съставки и автоматично изчисляване на хранителните стойности за една порция.
- **Седмично хранително меню** — организиране на храненията по дни и тип хранене.
- **Изчисляване на макронутриенти** — автоматично изчисляване на калории, протеини, въглехидрати и мазнини за ястията и храненията.
- **Персонализирана 404 страница** — показване на собствена страница при несъществуващ адрес.

## Инсталация и стартиране

### 1. Клониране на хранилището

```bash
git clone https://github.com/AlexanderHrHristov/plate-plotter-django.git
cd plate-plotter-django
```

### 2. Създаване на виртуална среда

```bash
python -m venv venv
```

Активиране на виртуалната среда под Windows (PowerShell):

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Инсталиране на необходимите библиотеки

```bash
pip install -r requirements.txt
```

### 4. Създаване на базата данни

```bash
python manage.py migrate
```

Командата създава необходимите таблици в SQLite базата данни чрез миграциите на Django.

### 5. Стартиране на приложението

```bash
python manage.py runserver
```

След стартирането приложението е достъпно на адрес:

http://127.0.0.1:8000/

## Как работи приложението

### 1. Продукти и наличности

Потребителят създава магазини и регистрира хранителни продукти, като посочва тяхната категория, цена, количество в опаковка и хранителни стойности.

За продуктите могат да се поддържат налични количества и минимални складови запаси.

### 2. Ястия и рецепти

Потребителят създава ястие, определя броя порции и добавя необходимите продукти с техните количества.

Приложението изчислява хранителните стойности за една порция въз основа на въведените съставки.

### 3. Седмично меню

Потребителят създава седмично меню и добавя хранения за различните дни.

Всяко хранене може да включва готово ястие и допълнителни хранителни продукти.

Приложението изчислява общите калории и макронутриенти за храненето.

## Технически особености

- Приложението използва архитектурата Model–View–Template (MVT) на Django.
- Използвани са Class-Based Views (CBV).
- Реализирани са форми за създаване и редактиране на данни.
- Използват се Django ORM и релации между моделите.
- Реализиран е персонализиран Django template filter.
- Добавена е собствена страница за HTTP грешка 404.
- Не се изисква регистрация или удостоверяване на потребители.
- Данните могат да бъдат въвеждани през потребителския интерфейс, без използване на Django Admin.

## Ограничения

- Приложението е разработено с учебна и демонстрационна цел.
- Хранителните изчисления изискват попълнени хранителни стойности.
- В текущата версия автоматичното изчисляване на макронутриентите е реализирано за продукти с количества в грамове.
- Базата данни се създава локално при изпълнение на миграциите.
